# Student Life Manager

A responsive React web app for managing university assignments, exams, daily tasks, deadlines, and study priorities.

## Features

- Dashboard statistics and progress tracking
- Task creation, editing, deletion, and completion
- Category, subject, priority, and title filters
- Monthly deadline calendar
- Study planner and resume page
- Browser persistence with localStorage
- Responsive desktop and mobile layout

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite in your terminal.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React
